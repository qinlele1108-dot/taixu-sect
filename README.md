# 太玄宗：掌门录

天青水墨风的单机修仙放置经营游戏。执掌太玄宗，安排弟子、经营宗门、炼制丹药、探索秘境，并从炼气一路突破至道祖。

## 游戏内容

- 十大境界与阶段突破
- 宗门建筑升级和弟子排班
- 80 种物品，八档品相
- 自动炼丹、秘境探索与离线收益
- Windows 本地版与浏览器版

## 浏览器版

仓库通过 GitHub Actions 自动部署 `web/` 目录到 GitHub Pages。浏览器存档保存在当前浏览器的站点数据中。

## 本地开发

使用 Godot 4.7.2 打开 `game/project.godot`。主场景为 `game/scenes/main.tscn`。
